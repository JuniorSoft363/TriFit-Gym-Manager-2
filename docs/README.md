# Documentación

En esta carpeta se suben los documentos del proyecto:

- `pruebas-playwright.md` — Casos de prueba definidos por el docente para Playwright.
- Cualquier otro documento (diagramas, manuales, informes).

## Convenciones

- Nombres de archivo en minúsculas, sin espacios, con guiones (kebab-case).
- Markdown (`.md`) para documentos de texto.
- PDF, imágenes, etc. en subcarpetas si son muchos archivos.
